# Proyecto Final — Desarrollo de Software VIII

Valor: 100 puntos.

Sistema IoT con Wokwi y Raspberry Pi Pico W (MicroPython): leer sensores, guardar datos con fecha, reaccionar a eventos (interrupciones y temporizadores), recibir comandos y mostrar datos en la nube.

Escenario elegido: **Cadena de Frío Farmacéutica**.

## Requisitos

- Mínimo 3 sensores
- Mínimo 3 actuadores
- Código en Python ordenado por módulos y comentado
- Cliente MQTT (HiveMQ)
- Base de datos SQLite: lecturas, eventos, comandos y consultas del historial
- Nube (ThingSpeak): panel en tiempo real y comandos hacia el dispositivo

## Entregables

- Código en GitHub y Teams: README, requirements.txt, scripts SQL, diagrama de arquitectura, capturas del circuito y zip de Wokwi
- Documentación: arquitectura, flujo de datos y configuración de la nube
- Sustentación oral
